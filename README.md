# CodTech Task 3 - Real-Time Dashboard

## Overview
A real-time Power BI dashboard powered by a Python simulated API feed.

## Files
- `CodTech_Task3_RealTimeDashboard.pbix` - Power BI Dashboard
- `stream_final.py` - Simulated API data streamer

## How It Works
1. Run `stream_final.py` to start the data stream
2. Open the `.pbix` file in Power BI Desktop
3. Click Refresh to see live data updates

## Tech Stack
- Power BI Desktop
- Python (openpyxl)
- Simulated API Feed (updates every 5 seconds)
